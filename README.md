# NiorbDev · Portafolio

Portafolio personal estático con una estética editorial retro. Las gráficas decorativas están hechas con CSS; no usa imágenes generadas ni librerías externas.

## Publicación

Este sitio está pensado para GitHub Pages. El repositorio especial NiorbDev.github.io se publica en:

https://niorbdev.github.io

La fuente de publicación es la rama main, desde la raíz. Para editar el sitio, modifica index.html, styles.css o script.js y sube los cambios a main.

## Proyectos incluidos

- EntreCapas — ropero digital y probador 2D.
- Color Block Jam Solver — búsqueda A* en C++.
- Detección de círculos con Hough — pipeline de procesos en C.

Diseño adaptable a móvil y con una preferencia de movimiento reducido para quienes la activan en su dispositivo.
