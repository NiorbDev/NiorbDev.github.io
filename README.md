# NiorbDev · Portafolio

Portafolio personal con una dirección editorial brutalista, tipografía monumental y movimiento hecho con CSS y JavaScript. Los adornos y dibujos temporales son SVG/CSS; el retrato principal es una imagen aportada por Nico.

## Publicación

El sitio se publica con GitHub Pages desde la rama main, en https://niorbdev.github.io.

## Imágenes

El retrato principal está en assets/niorb-portrait.png. Las cuatro láminas del carrusel tienen espacios de reemplazo y nombres listos dentro de assets/gallery/. Los prompts, la paleta y las instrucciones para añadir las imágenes están en assets/PROMPTS.md.

## Proyectos incluidos

- EntreCapas — ropero digital y probador 2D.
- Color Block Jam Solver — búsqueda A* en C++.
- Detección de círculos con Hough — pipeline de procesos en C.

El sitio se adapta a móvil y respeta prefers-reduced-motion.
